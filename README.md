## 🚀 Começando

Primeiro de tudo você precisa ter o [Node.js](https://nodejs.org/) e [npm](https://www.npmjs.com/) instalado na sua máquina.

Então você pode clonar o repositório.

```code
git clone https://github.com/zehguilherme/personal-curriculum
```

Inicialize a aplicação

1. `cd frontend`
2. `npm install`
3. `npm start`

## 🤔 Como contribuir

1. Faça um fork desse repositório;
2. Crie uma branch com a sua feature: `git checkout -b minha-feature`;
3. Faça commit das suas alterações: `git commit -m 'feat: Minha nova feature'`;
4. Faça push para a sua branch: `git push origin minha-feature`;
5. Crie um pull request;
6. Depois que o merge da sua pull request for feito, você pode deletar a sua branch.
